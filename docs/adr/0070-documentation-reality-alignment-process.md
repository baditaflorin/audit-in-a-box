# 0070 - Documentation-Reality Alignment Process

## Status

Accepted

## Context

Phase 3 treats mismatched claims as user-facing bugs.

## Decision

README claims must map to UI controls, API docs, or tests. Claims that cannot be tested locally are moved to limitations or removed. The smoke test must cover the live Pages shell and at least one output/control path.

## Consequences

Docs become a tested surface, not marketing drift.

## Alternatives Considered

Keeping aspirational roadmap claims in README was rejected.
